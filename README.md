# AUTOVERSE — simplified

Projeto reduzido para 3 áreas principais:
- `/` — Home
- `/news` — Notícias + páginas individuais dos artigos
- `/cars` — Banco de carros

Todo o CSS está em `app/globals.css`.
Não há styled-jsx, CSS modules ou Tailwind.

## Instalação

```bash
npm install
npm run dev
```

Depois acesse http://localhost:3000
